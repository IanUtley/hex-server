This folder is used to store effect abilitity setup and executions.
i.e. How to package up effect abilities for the client to execute, and what needs
to be done to the database model, so that the client can show the correct view.

README.md describes how to layout files and how to contribute.
ABILITIES.md is generated from the C# classes, showing which parts of the gamedata JSONL are used
by the game to implement an ability. This document should be consulted when generating leaf executors.
